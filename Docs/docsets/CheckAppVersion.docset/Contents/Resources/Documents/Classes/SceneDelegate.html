SceneDelegate

@MainActor
class SceneDelegate : UIResponder, UIWindowSceneDelegate

The SceneDelegate class is responsible for managing the life cycle of the app’s scenes. It handles tasks such as setting up the window, responding to scene transitions, and managing resources.

    The window of the app’s user interface. This is where the root view controller and its view hierarchy are managed.
